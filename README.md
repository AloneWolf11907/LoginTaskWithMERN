# LoginTaskWithMERN
A full-stack user authentication system built with React, Express.js, and MongoDB. This application provides secure user registration and login functionality with a modern, responsive UI. 

🚀 Features
User Registration: Create new accounts with name, email, and password

User Login: Secure authentication for existing users

Responsive Design: Works on desktop and mobile devices

Form Validation: Client-side form validation

Modern UI: Clean and user-friendly interface using Bootstrap

Secure Backend: Password hashing and secure API endpoints

🛠️ Tech Stack
Frontend
React.js - Frontend library

Vite - Build tool and development server
